Що таке DayFlow?

DayFlow — це планер задач, який допомагає організовувати день, контролювати задачі та слідкувати за прогресом.

Що можна робити?

  • Додавати задачі
  • Видаляти задачі
  • Позначати виконані
  • Фільтрувати список
  • Дивитись статистику
  • Змінювати тему сайту

Які технології використані?

HTML — структура сторінок

CSS — оформлення та адаптивність

JavaScript — логіка та взаємодія

LocalStorage — збереження задач

Для кого цей сайт?

Для учнів, студентів та всіх, хто хоче планувати свій день та бути продуктивнішим.
